# SAS for Microsoft 365

Learn how to use SAS®  for Microsoft 365 to seamlessly access and share analytical insights produced by SAS®  Viya®  in your Microsoft Office applications. You can integrate results and data from your SAS®  Visual Analytic reports, SAS®  Viya®  Jobs, and SAS®  programs into Microsoft Excel, PowerPoint, Outlook and Word.
